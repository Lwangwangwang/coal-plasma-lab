它对煤炭转化提供什么？

电能 / 放电→高焓热流与活性组分→煤粉快速受热 / 气化强化
重要区别：热等离子体的主要作用往往是提供高温和高焓；非热等离子体则可能更强调高能电子和活性粒子反应。两者不能简单用同一种“温度”描述。

再看两个决定反应器设计的概念

A

供电功率 ≠ 有效反应热

Pel = U I

对直流电弧等离子体炬，电功率可以用电压与电流的乘积表示。但部分输入能量会通过电极冷却、炉壁散热及尾气显热等途径流失。

B

升温快并不等于颗粒内部瞬间等温

tcond ∝ dp2 / αp

颗粒内部导热特征时间与粒径平方同量级相关。煤粉粒径和分散程度影响进入高温区后能否及时升温、析出挥发分及充分转化。

从等离子体进入化学反应

流动

射流把热量带入反应区，并使煤颗粒在流动场中分散、迁移。

传热与传质

高温流体向颗粒传热；反应物扩散到表面、产物进入气流。

反应

煤中有机结构裂解形成小分子；煤焦与气化剂反应形成CO、H₂。

煤粉预处理

原料输入与适配

    高温裂解为什么需要急冷？

    高温形成阶段

    煤中有机组分裂解，形成挥发分、自由基和乙炔等小分子。

    高温继续停留

    乙炔可能继续分解或参与成炭反应，造成目标产物损失。

    快速急冷阶段

    迅速降温以抑制二次反应，有利于保留已形成的乙炔。

    分离回收阶段

    从混合裂解气中去除颗粒和杂质，并依据产品要求富集乙炔。

    交互实验：改变操作策略，观察定性变化

    不同于真实反应动力学模型，以下仅用于理解变量之间的作用方向

    相对等级：低 → 高
    相对等级：短 → 长
    相对等级：弱 → 强

    乙炔保留条件：较有利

    快速升温配合较短的高温停留时间与较强急冷，有利于目标中间产物的生成与保留。

    观察重点

    裂解充分性（示意）中高
    二次分解风险（示意）偏低
    教学规则只呈现趋势关系，不提供乙炔产率、最佳温度或真实毫秒数的预测。实际工况必须依据煤质、装置结构和实验/模型数据确定。

      水蒸气气化 · 吸热

      通过Boudouard反应生成CO。

      部分氧化 · 放热
      C + ½O₂ → CO

      氧气参与可提供化学反应热。

      水煤气变换 · 可逆
      CO + H₂O ⇌ CO₂ + H₂

      影响合成气H₂/CO与CO₂组成。

      选择气化剂（单独考察其影响）

      水蒸气气化

      C + H₂O → CO + H₂

      吸热反应，需要充足的热量支持；在合适条件下有利于H₂生成，并可通过水煤气变换调节组成。

      等离子体供热与有效反应时间

      反应条件：较有利

      对水蒸气或CO₂气化，充足的高温供热和气固接触通常有利于吸热转化反应进行。

      气化剂在工程上常采用混合方案。此处“单独选择”只用于辨析不同气化剂的化学作用；真实H₂/CO比例、碳转化率、冷煤气效率取决于煤质、装置与全部操作条件。

      为什么同一种等离子体技术，会形成两条工艺？

      对比分析 · 自测反馈
      比较维度路线 A：煤制乙炔路线 B：辅助煤气化
      目标产物乙炔富集裂解气，需进一步分离以CO、H₂为主的合成气，可用于化工合成或制氢
      主导化学过程煤有机组分高温快速热解、裂解及气相反应煤焦与H₂O、CO₂等气化剂进行气固反应，并伴随气相反应
      关键操作变量煤粉粒径、供热强度、高温停留时间、急冷速度供热方式、气化剂种类与用量、气固接触、反应时间
      为什么需要高温促进复杂有机结构断裂，形成小分子中间产物为煤焦气化等吸热反应提供热量并促进动力学转化
      为什么需要后处理快速急冷抑制乙炔二次分解；除尘、洗涤、分离冷却或余热回收；除尘、脱硫和组分调节
      核心装置等离子体炬、裂解反应器、急冷器、分离净化设备等离子体炬、气化炉、余热回收和合成气净化设备
      工程应用边界已有兆瓦级中试/工程验证，长期普遍商业化仍需核实存在实验与中试及部分工程研究，需区分煤与其他固体原料案例

      对同一问题，从不同化工角度理解

      热量从哪里来？

      既要看电功率和等离子体炬效率，也要核算炉体损失、急冷与余热回收过程。

      反应物如何接触？

      气固两相流动、湍流混合、颗粒升温与扩散反应共同限制最终转化表现。

      为什么不能只看转化率？

      乙炔路线还需看选择性、积炭与分离成本；气化路线还需看合成气品质及整体能效。
